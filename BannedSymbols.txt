// BannedSymbols.txt: the house "no hacks" list for Microsoft.CodeAnalysis.BannedApiAnalyzers (RS0030).
// Ship it at the repository root and wire it in Directory.Build.props (see the dotnet-practices skill, section 12).
//
// Comments start with //. A line starting with # is NOT a comment: the analyzer parses it as an (invalid) entry,
// so it bans nothing, and two identical # lines fail the build with RS0031 ("listed more than once").
//
// Never suppress RS0030 to get around this list in our own code; fix the code. Bend the rule only where code we
// don't own forces it, and only as locally as possible (see the skill, section 12):
// - the composition root/entry point: `#pragma warning disable RS0030 // reason` around the one line;
// - generated or library code that trips it: the library's own switch first (xunit v3: define
//   XUNIT_GENERATED_DISABLE_WARNINGS), else a pragma around the single call into the library.
// Never <NoWarn>RS0030</NoWarn>, and never rewrite library plumbing (such as xunit's entry point) to dodge the list.
//
// Format: <DocId>;<message>   (T: type, M: method, P: property, F: field, E: event, N: namespace)
// - A method WITHOUT a parameter list bans only the parameterless overload. There are no wildcards:
//   list every overload you mean, or ban the whole type with T:.
// - Generic types use a backtick plus the arity (Task`1), generic arguments use braces (Action{Task}),
//   constructors are #ctor.
// Every active entry below was verified to fire on .NET 10 / BannedApiAnalyzers 5.6.0. These were verified NOT to fire:
// the lock statement (Monitor.Enter(object, ref bool)), await (implicit GetResult), Task.Run(async () => ...),
// ToLowerInvariant, and Parse(s, CultureInfo.InvariantCulture).
